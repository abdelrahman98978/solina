# التوثيق المحاسبي والضريبي لمنصة سولينا للسيارات (SOCPA / ZATCA Phase 2 / SAMA)

توضح هذه الوثيقة المعادلات المحاسبية والضريبية والتمويلية المعتمدة في المحرك الأساسي [`src/utils/erpCore.ts`](../src/utils/erpCore.ts) لأغراض المراجعة المالية والضريبية.

---

## 1. المعالجة المحاسبية بالهللة (Integer Halala Arithmetic)
لتجنب أخطاء الفاصلة العائمة (`IEEE 754 Floating-Point Drift`)، يتم تحويل كافة المبالغ بالريال السعودي إلى **هللات صحيحة** قبل إجراء أي عملية جمع أو طرح أو تقسيم ضريبي:

$$\text{Halalas} = \text{round}(\text{SAR} \times 100)$$

---

## 2. فصل ضريبة القيمة المضافة ومعالجة الخصومات (VAT & Discounts)
- **المبلغ شامل الضريبة (`splitVatInclusive`)**:
  $$\text{Subtotal}_{\text{halalas}} = \text{round}\left(\frac{\text{Total}_{\text{halalas}}}{1 + r}\right), \quad \text{VAT}_{\text{halalas}} = \text{Total}_{\text{halalas}} - \text{Subtotal}_{\text{halalas}}$$
  مما يضمن تطابق $\text{Subtotal} + \text{VAT} = \text{Total}$ دون أي فرق هللة.
- **الخصم التجاري قبل الضريبة (`applyDiscountBeforeVat`)**:
  يُخصم مبلغ الخصم من الوعاء الخاضع للضريبة قبل احتساب ضريبة القيمة المضافة وفق لائحة هيئة الزكاة والضريبة والجمارك.
- **التصنيفات الضريبية (`ZatcaTaxCategory`)**:
  - `S`: خاضع للنسبة الأساسية (15% افتراضياً وقابلة للضبط من إعدادات النظام).
  - `Z`: خاضع لنسبة الصفر بالمائة (0% — مثل الصادرات المعتمدة).
  - `E`: معفى من الضريبة (0%).
  - `O`: خارج نطاق الضريبة (0%).

---

## 3. الفوترة الإلكترونية (ZATCA Phase 1 & Phase 2 — الفاتورة)
1. **ترميز TLV QR Code (`buildZatcaQrBase64`)**:
   يتم بناء مصفوفة بايتات ثنائية (`Uint8Array` بترميز `UTF-8`) للحقول الإلزامية (1 إلى 8) ثم تحويلها إلى `Base64` قياسي، مع رفض أي رقم ضريبي لا يطابق الصيغة السعودية (`^3\d{13}3$`).
2. **سلسلة التجزئة التراكمية (`PIH — Previous Invoice Hash`)**:
   تحمل الفاتورة الأولى قيمة التأسيس القياسية (`NWZlY2ViNjZmZmM4NmYzOGQ5NTI3ODZjNmQ2OTZjNzljMmRiYzIzOWRkNGU5MWI0NjcyOWQ3M2EyN2ZiNTdlOQ==`)، وتحسب كل فاتورة لاحقة بصمة `SHA-256` لبصمة الفاتورة السابقة مع بيانات الفاتورة الحالية، مع عداد تسلسلي غير قابل للتكرار (`ICV`).
3. **إلغاء الفواتير المرحلة**:
   يُمنع حذف الفواتير المعتمدة أو المرحلة، ويتم التعديل حصراً عبر إصدار **إشعار دائن (`Credit Note — 381`)** مرتبط برقم الفاتورة الأصلية.

---

## 4. معادلة التمويل التأجيري والمرابحة والإفصاح الائتماني (SAMA)
تميز الحاسبة التمويلية (`calculateMurabahaFinance`) بوضوح بين:
- **هامش الربح السنوي الثابت (Flat Annual Murabaha Margin)**.
- **معدل النسبة السنوي الفعلي التقريبي (Effective APR)** المحسوب على الرصيد المتناقص مع إدراج الرسوم الإدارية (بحد أقصى 1% أو 5,000 ر.س أيهما أقل وفق تعليمات البنك المركزي السعودي SAMA).
